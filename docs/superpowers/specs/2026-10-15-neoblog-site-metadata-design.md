## 1. 意图与背景

`site` 组六键（0.19.0 + 0.20.1）与 `/console/settings/general` 的读写接线（本轮前已入库）都做完了，但这些值**在项目里一个消费方都没有**：根 `layout.tsx` 的 metadata 至今是 create-next-app 的脚手架文字（`"Create Next App"` / `"Generated by create next app"`），子页只回各自标题、控制台子页干脆没标题，`block_search_engines` / `site.url` 无人读。本轮把它们接进前台的真实位置，并顺带把控制台各页的标签标题补齐。

**现状（实读）**：

- 根 `layout.tsx:22-25` 静态 `metadata`（脚手架文字）、`:27` `export const instant = false`（全站动态渲染，既有口径）。
- `lib/public-settings.ts:40-54` `getPublicSettings()`：`cache: "no-store"`（每请求读）+ fail-open（读不到返回 `{}`）；`:56-58` `isSignupOpen` 是唯一消费者（登录页/注册页的注册闸）。
- 有自己标题的页只有三个：`app/console/page.tsx:4-10`（控制台）、`app/signin/page.tsx:11-17`（欢迎回来）、`app/signup/page.tsx:11-17`（创建账号）；`/console/uc/*` 与 `/console/settings/*` 四页没有标题（浏览器标签吃的就是根默认）。
- **没有** `app/robots.ts`、没有 `app/sitemap.ts`；`public/` 只有脚手架 SVG。
- 侧栏文案键（`messages/zh-CN.json:19-29`）：`sidebar.personalInfo`=个人信息、`sidebar.sessions`=登录会话；设置区：`settings.general`=常规、`settings.register`=用户注册。
- 后端公共读现成：`GET /api/v1/public/settings`（无鉴权聚合读，site 六键全公开，未落库项回默认值）——**本轮后端零改动**。
- 对照（D 盘 HaoBlog）：控制台标题拼法是「页面名 | 网站后台」（`lib/console-i18n/titles.ts`）——**本仓明确不取这个后缀**；其 `lib/theme/root-metadata.ts` 的 robots meta 双做与 `lib/settings/public-cache.ts` 的缓存口径可作参照。

## 4. 设计条文

### 4.1 纯模块契约（`lib/site-metadata.ts`）

模块**零 import**、参数一律收 `unknown`（调用方传 `PublicSettings` 天然兼容；好处是可单文件离线编译做断言）：

```ts
export function siteTitle(settings: unknown): string;          // 原始站名（trim 后）
export function siteSubtitle(settings: unknown): string;
export function composeSiteTitle(title: string, subtitle: string): string; // 非空段 " - " 连接；全空 = ""
export function siteDocumentTitle(settings: unknown): string;  // composeSiteTitle(siteTitle, siteSubtitle)
export function siteDescription(settings: unknown): string;
export function siteKeywords(settings: unknown): string[];     // 逗号拆分（半角/全角都认）、逐段 trim、丢空段
export function siteBaseUrl(settings: unknown): URL | null;    // new URL 成功才返回；空/非法 = null
export function blocksSearchEngines(settings: unknown): boolean;
```

规则细节：缺组 / 缺键 / 非字符串 → 一律空值（fail-open，与读取层同口径）；所有字符串先 trim 再判空；`composeSiteTitle` 不产生悬空分隔符（`"A - "` 这种永远不出现）。

### 4.2 根 `layout.tsx` 的 `generateMetadata()`

读 `getPublicSettings()`（60 秒缓存），逐项**配了才输出**（空则不产出该字段）：

- `title` = `siteDocumentTitle(settings)`；
- `description` = `siteDescription(settings)`；
- `keywords` = `siteKeywords(settings)`（空数组不输出）；
- `metadataBase` = `siteBaseUrl(settings)`（null 不输出）；
- `robots: { index: false }` 仅 `blocksSearchEngines(settings)` 为真时；
- `openGraph`：`title`（拼好的标题）、`description`（配了才带）、`siteName`（站名，配了才带）。

`instant = false` 维持不动（全站动态渲染）；本函数每次渲染读一次公开设置（60 秒缓存兜底，不产生每请求的后端查询）。

### 4.3 `app/robots.ts`

```ts
export default async function robots(): Promise<MetadataRoute.Robots>
```

- 开关开：`{ rules: [{ userAgent: "*", disallow: "/" }] }`；
- 开关关：`{ rules: [{ userAgent: "*", allow: "/", disallow: "/console" }] }`；
- **60 秒缓存**（`revalidate` 口径；Next 16 `cacheComponents: true` 下具体落地形式以实现时构建结果为准，验收口径固定：改开关 ≤60 秒生效、且不是每请求取数）；
- 读取走 `getPublicSettings()`（fail-open：读不到 = 开关关 = 放行 + `/console` disallow）。

### 4.4 控制台页面标题（D3）

四个页面各加一个 `generateMetadata()`（服务端、`getTranslations`）：

| 页面 | 文案键 | 值 |
| --- | --- | --- |
| `uc/profile` | `sidebar.personalInfo` | 个人信息 |
| `uc/session` | `sidebar.sessions` | 登录会话 |
| `settings/register` | `settings.register` | 用户注册 |
| `settings/general` | `settings.siteSettings`（**新键**） | 站点设置 |

其余页（`/console`、`/signin`、`/signup`）不动。文案键选「与侧栏项同名」的键（general 页除外——标签名与侧栏名不同，故新键），en 同键位。

## 5. 边界条件与已知风险

- **B1 缓存连带注册闸**（D1）：关闭注册后前台最多 1 分钟才隐藏入口 / 404；这是用户拍板接受的取舍，DEVLOG 如实登记。
- **B2 全部未配置时**：标题为空、无 description / keywords / OG——不兜底（用户点名）。浏览器标签会显示 URL，搜索结果摘要由搜索引擎自取；这是有意行为，不是缺陷。
- **B3 拼装规则单点**：空段丢弃、`" - "` 连接只在 `composeSiteTitle` 一处；离线断言 + 变异自检钉住（不产生悬空分隔符）。
- **B4 robots.txt 缓存的 API 口径**：Next 16 + `cacheComponents: true` 下 `revalidate` / fetch 缓存的具体组合以实现时 `next build` 验证为准；验收 = 改开关 ≤60 秒生效、非每请求取数。
- **B5 后台标题与侧栏是「同键不同处」**：personalInfo / sessions / register 三页与侧栏共用同一文案键（改名自动同步）；general 页因标签名（站点设置）与侧栏名（常规）不同，是两个键——将来改名要改两处，登记。
- **B6 后台页面会继承站点级 description / keywords / OG**（根 metadata 合并规则使然）：无实际影响（后台不进搜索引擎），不额外屏蔽。
- **B7 `/console` 的 robots.txt disallow 是硬编码**：没有设置项控制；将来若换后台路由前缀要同步改。
- **B8 无测试运行器**（沿用既有缺口）：防回归 = `tsc` / `eslint` / `prettier --check` + 离线纯函数断言（`.superpowers/sdd/…`，不入库）+ `next build`（验证路由配置）+ 用户实机验收。

## 6. 明确不做

canonical / OG url / `og:image` / 分享卡片；后端邮件链接基址（后端轮）；副标题上登录 / 注册页；「\| 网站后台」类标题后缀；侧栏项与页面 h1 改名；站点图标 / favicon 接线（无上传接口）；`/ui-check`、`/tabs-demo` 的标题治理；sitemap；国际化标题（站名 / 描述是管理员配置值，不随语言切换）。
